# Archived maintenance scripts

These scripts belong to the old repository layout. They are preserved for
reference only and are not invoked by the new root pipeline.

`clean.sh` can recursively delete caches and can invoke `git clean`; do not run
it against either new repository. The naming-audit scripts check obsolete
`EW_*` and `CY_LLM_*` migration paths.

# 归档的维护脚本

这些脚本属于旧仓库布局，仅保留作参考，不会由新的根 pipeline 调用。
