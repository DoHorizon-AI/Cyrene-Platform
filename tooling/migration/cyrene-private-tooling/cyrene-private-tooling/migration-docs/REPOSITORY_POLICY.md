# Private repository policy

This repository contains private advanced-service implementations and legacy
migration source. It is not the public CYRENE core repository and must not be
mirrored into the public GitHub organization.

No deployment status should be inferred from source presence. Only root-level
CI definitions are active; files below a `legacy` directory are historical.
Before any external distribution, the repository owner must complete a license,
third-party notice, secret, and dataset-rights review.
