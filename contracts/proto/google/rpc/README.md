# Vendored Google RPC status contract

`status.proto` is the locally controlled copy of the standard Google RPC
status message from googleapis/googleapis. Source:
`google/rpc/status.proto` in the googleapis/googleapis repository. The upstream
definition is Apache-2.0 licensed; this tracked copy is also SPDX:
Apache-2.0.

Its package and wire shape are kept unchanged so Core v1 descriptors are
reproducible without a developer-local Proto installation.

The file is intentionally tracked with the contract module and must be
updated together with its source/license record when the upstream definition
changes.

# Vendorized Google RPC Status 契约

`status.proto` 是由本地控制的 googleapis/googleapis 标准 Google RPC status message 副本。来源为 googleapis/googleapis 仓库中的 `google/rpc/status.proto`。上游定义使用 Apache-2.0 许可证；此跟踪副本也标记为 SPDX：Apache-2.0。

为确保 Core v1 descriptor 可重复生成且无需开发者本地安装 Proto 工具，其 package 和 wire 结构保持不变。

该文件有意与契约 module 一同跟踪；上游定义发生变化时，必须同时更新此文件及其来源/许可证记录。
