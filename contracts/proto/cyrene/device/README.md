# Cyrene Device Protocols | Cyrene Device 协议

## Purpose | 目录职责

This namespace contains Cyrene-owned WorkspaceDevice identity and enrollment
contracts. It does not own Product resources or Workload identity.
本命名空间承载 Cyrene 自有的 WorkspaceDevice 身份与注册契约，不拥有 Product resource 或 Workload identity。
