# fixtures Directory Guide | contracts/fixtures 目录指南

## Purpose | 目录职责

This directory contains checked-in compatibility fixtures used to make contract projections concrete.
本目录存放已纳入版本控制的兼容性 fixture，用于把契约投影落到可执行样例。

## Contents | 内容

| Entry | Responsibility | 一句话职责 |
| --- | --- | --- |
| `core/` | Core contract fixtures. | Core 契约 fixture。 |
| `semantic/` | Semantic contract fixtures. | 语义契约 fixture。 |

## Suggested reading / execution order | 推荐阅读 / 执行顺序

Read the semantic fixture first, then the core and control-plane projections.
先读语义 fixture，再读 Core 与 control-plane 投影。
