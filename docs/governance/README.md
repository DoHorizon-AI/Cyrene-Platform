# Governance | 治理

This directory defines ownership, repository lifecycle, CI trust, and delivery
rules for the public Core boundary.

本目录定义公共 Core 边界的责任归属、仓库生命周期、CI 信任与交付规则。

| File | Responsibility | 文件职责 |

| `ci-trust-model.md` | CI evidence and trust boundaries. | CI 证据与信任边界 |

| [`PUBLIC_RELEASE_PREFLIGHT.md`](PUBLIC_RELEASE_PREFLIGHT.md) | Current-publication preflight and evidence status. | 当前公开发布前检查与证据状态 |
