# Start Here | 入门

This directory provides the guided onboarding path for understanding the
CYRENE repository and locating the correct ownership boundary for a change.

本目录提供 CYRENE 仓库的入门路径，帮助读者理解仓库并为改动找到正确的责任边界。

| File | Responsibility | 文件职责 |
| --- | --- | --- |
| `00-what-is-cyrene.md` | System purpose and vocabulary. | 系统目标与词汇 |
| `01-system-map.md` | High-level system map. | 系统总览图 |
| `02-repository-map.md` | Platform ownership and external catalog authority. | Platform 归属与外部目录权威 |
| `03-where-does-my-code-go.md` | Change-placement guide. | 改动归属指南 |
| `04-first-development-task.md` | First-task walkthrough. | 首个开发任务流程 |
| `05-how-to-read-the-codebase.md` | Platform code-reading method. | Platform 代码阅读方法 |
| `first-clone.md` | First Platform checkout guidance. | Platform 首次检出指南 |

## Suggested reading | 推荐顺序

Read the numbered files from `00` through `05`; use `first-clone.md` when
setting up a fresh checkout.

按 `00` 至 `05` 的编号顺序阅读；新建工作区时再参考 `first-clone.md`。
