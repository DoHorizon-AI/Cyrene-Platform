# CYRENE Glossary | CYRENE 术语表

| English | 中文 | Meaning |
| --- | --- | --- |
| Kernel | 内核 | Node-local authority for leases, fencing, lifecycle, and generic transport. 节点本地的租约、围栏、生命周期与通用传输权威。 |
| Framework | 框架层 | Policy, discovery, registry, and extension composition layer. 策略、发现、注册与扩展组合层。 |
| Contract | 契约 | Versioned semantic or wire agreement between components. 组件之间版本化的语义或线协议约定。 |
| Capability | 能力 | A typed operation a plugin or provider can implement. 插件或 Provider 可实现的强类型操作。 |
| Provider | 提供者 | Component that exposes a resource, model, or capability to the host. 向主机暴露资源、模型或能力的组件。 |
| Worker | 工作进程 | Out-of-process implementation activated and supervised by the host. 由主机激活并监管的进程外实现。 |
| Lease | 租约 | Time- and fence-scoped right to use a resource. 带时间与围栏范围的资源使用权。 |
| Fence token | 围栏令牌 | Monotonic token preventing stale holders from acting. 防止旧持有者继续操作的单调令牌。 |
| Adapter Host | 适配器主机 | Separately supervised process for privileged or vendor-specific operations. 独立监管、负责特权或厂商操作的进程。 |
| TCK | 技术兼容性套件 | Cross-language conformance vectors and runners. 跨语言一致性向量与运行器。 |
| Projection | 投影 | Transport or language representation of an authoritative semantic model. 权威语义模型在传输或语言中的表示。 |
| Reconciliation | 协调 | Converging desired state and observed lifecycle evidence. 让期望状态与观测生命周期证据最终一致。 |
