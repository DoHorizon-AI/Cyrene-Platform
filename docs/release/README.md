# Release Guides | 发布指南

This directory describes how components, artifacts, versions, tags, and
distribution targets relate to one another.

本目录说明组件、产物、版本、标签与分发目标之间的关系。

| File | Responsibility | 文件职责 |
| --- | --- | --- |
| `component-vs-distribution.md` | Component versus distribution distinction. | 组件与分发的区别 |
| `distribution-manifest.md` | Distribution manifest semantics. | 分发 Manifest 语义 |
| `artifact-destinations.md` | Artifact destination policy. | 产物目标策略 |
| `versioning-model.md` | Versioning rules. | 版本规则 |
| `tagging.md` | Tagging rules. | 标签规则 |
| `release-topology.md` | Release topology. | 发布拓扑 |
| `PUBLIC_PACKAGE_RELEASE_ORDER.md` | Public Rust package publication DAG and dry-run procedure. | 公共 Rust 包发布依赖顺序与 dry-run 流程 |

## Suggested reading | 推荐顺序

Read `component-vs-distribution.md`, `versioning-model.md`, and
`release-topology.md` before preparing a release.

准备发布前先读 `component-vs-distribution.md`、`versioning-model.md` 和
`release-topology.md`。
